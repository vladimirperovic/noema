Noema is a calm, three-day to-do list — yesterday · today · tomorrow — that doubles as a self-hosted gateway exposing your tasks to AI assistants over MCP and OpenAPI.

01 What Noema is

Noema (Greek νοήματος — “what is held in mind”) keeps you focused on a short horizon: what was left from yesterday, what matters today, what is coming tomorrow. There is nothing to install — it is plain Node.js with zero dependencies.

Behind the simple board there is a gateway: every task operation is also available to large language models (Claude, ChatGPT) and to Siri, so you can ask “what's left for me today?” in natural language and get a real answer from your own data.

02 The three-day board

The home screen has three columns. Today is the beacon in the middle; yesterday sits to the left as “what remains”, and tomorrow to the right as “what's next”.

Yesterday

What you didn't finish. A gentle reminder, not a graveyard.

Today

Your focus. New tasks land here by default.

Tomorrow

Planned ahead so today stays clear.

Add a task by typing in a column. Double-click (or double-tap on mobile) a title to edit it, tap the circle to complete it, tap the priority chip to cycle it, and the clock to set a time.

03 How tasks roll over & disappear

This is the most important idea in Noema, and the most common question. A task does not store the word “today”. It stores an absolute date (scheduledFor, e.g. 2026-06-29). The column it appears in is computed live against the real current date:

  • scheduledFor < today → shown under Yesterday
  • scheduledFor === today → shown under Today
  • scheduledFor > today → shown under Tomorrow

Because of this, the board “moves” on its own as midnight passes — you don't press anything:

  • A task you put in Tomorrow automatically becomes Today when the new day begins.
  • An unfinished Today task automatically slips into Yesterday as “remaining”.
Why a task vanishes from the board The board only shows the window yesterday → today → tomorrow. The moment a task's date becomes older than yesterday (two or more days in the past), it is hidden from the main screen so it can't pile up forever. It is not deleted — it lives on in the Archive, searchable by exact date. So “it disappeared” means “it rolled past yesterday”, never “it was lost”.
Note Completed tasks behave the same way — they stay visible while still in the yesterday/today/tomorrow window, then settle into the Archive once their date moves on.

04 Tasks: priority, time & repeat

Priority

Each task carries a priority — high, normal, or low (medium is accepted as a legacy alias for normal). High-priority, unfinished tasks sort to the top of a column.

Time

A task can have an optional time in 24-hour HH:MM form (e.g. 09:30). Loose input like 9:5 is normalized to 09:05. A task without a time is an “all-day” item; timed tasks sort before untimed ones.

Time Blocking

By assigning a time to a task in the Today column, you automatically activate a visual timeline. Timed tasks shift to the right, receive a bronze timeline marker (vertical line and a dot), and sort chronologically. This turns your "Today" column into a visual agenda.

Subtasks

Click the + Subtask button at the bottom of any task to break it down. Subtasks act as a lightweight checklist inside the main task, and can be checked off individually.

Repeat

A task can recur: daily, weekdays (Mon–Fri), weekends (Sat/Sun), or a specific weekday (mon … sun). Each day the server creates that day's instance once — if a matching task already exists for the day, it is not duplicated.

05 Notes & Documents

Notes

Notes are lightweight checklists: a title plus a list of items you can tick off. Good for shopping lists, packing, quick sub-tasks.

Network of Thought (Backlinks) You can link notes together by typing [[Note Title]] in a checklist item. When viewing a note in Preview mode (the eye icon), it automatically scans all other notes and lists backlinks (notes that link to the current one) at the bottom. This allows you to build a connected web of thoughts.

Documents

Documents are richer, free-form rich-text notes with a label. You can also upload a file — text files become editable document bodies, and other files (PDF, Word…) are stored and linked. Uploaded files are served back from /uploads/<name>.

06 AI Projects & Ctrl+V Screenshot Pasting

The AI Projects catalog displays your AI models, workspaces, tools, and servers in a clean 3-column visual card grid.

  • Direct Link Cards — Each card's top header banner and preview frame act as a direct link to open the target project URL in a new tab.
  • Instant Ctrl+V Screenshot Pasting — Take a screenshot of any website (Cmd+Shift+4 on Mac or Snipping Tool on Windows), open the edit dialog (✎), and press Ctrl+V / Cmd+V anywhere inside the form. The image is instantly captured, optimized, and saved to the card!
  • Pinning & Filtering — Pin high-priority projects with the ◆ icon to keep them at the top, and filter by custom labels (e.g. models, cloud, workspace).

07 Building Site (Gradilišta) & Maps

The Building Site module organizes architectural construction projects, photo albums, and site updates.

  • Photo Timeline & Year Slider — Browse site photos chronologically with a vertical scroll-synced year slider (2025, 2024, 2023...). Clicking any year scrolls directly to that section.
  • Leaflet Map Geocoding — View construction locations on an interactive map with GPS markers, address geocoding, and custom hotspot annotations on site photos.

08 Stats & SEO Analytics

The Stats page shows verified website telemetry without generated or silent fallback values.

  • Google Analytics 4 — Direct service-account visitor trend; the chart and seven-day table are generated from the exact same daily series.
  • Google Search Console Analytics — Direct daily clicks, impressions, CTR, and average position with all-project and per-site charts. GSC delay is shown explicitly and data older than three days is marked stale.
  • Freshness & Error Status — Every response shows the latest available Search Console date and is explicitly marked LIVE, PARTIAL, STALE, or UNAVAILABLE.
  • PageSpeed Insights — Direct desktop/mobile Lighthouse performance and lab LCP tests, cached for six hours to protect Google API quota.
  • Server Telemetry — Real-time CPU, RAM, and Disk utilization monitor.

09 Archive

The Archive is the long-term memory the board deliberately hides. It shows every task by its absolute date, plus notes, documents and snapshot dates, on a calendar.

  • Calendar — dots mark days that have tasks (amber), documents (green), saved links (blue) or backups (red). Click a day to see it.
  • Day / All — view a single day, or everything at once.
  • Search — filter the open day, or search your entire history (press / to jump to search). Clicking a result jumps to that day.

10 Links & Reader Mode

The Links page is a personal “linkdump”: a place to throw in anything interesting you stumble upon — an Instagram post, an article, a product page — and sort through it later. Every saved link becomes a preview card with the page's image (Open Graph og:image), title, domain and description, so you remember at a glance why you saved it.

Saving, labels & search

  • Paste a URL into the field at the top — the server fetches the page's title, description and image automatically.
  • Labels — every link can carry one free-form label (e.g. instagram, recipes, work). The label pills above the grid act as filters; click a card's label pill to change it. Labels get a stable colour derived from their name.
  • Search — press / or click the search field; it matches titles, descriptions, URLs and labels.
  • No duplicates — saving the same URL twice updates the existing card instead of creating a copy.
  • Archive — each saved link also appears in the Archive calendar on the day you saved it, marked with a blue dot, and is included in the global archive search.

Reader Mode

Every link card features a 📖 (Read) icon. Clicking it activates Reader Mode: Noema fetches the live web page, strips out all ads, menus, and boilerplate HTML, and presents you with a clean, distraction-free reading experience covering the full screen. This runs entirely locally via our zero-dependency parser.

The bookmarklet — save from any browser, any computer

A bookmarklet is an ordinary browser bookmark whose “address” is a tiny piece of JavaScript instead of a URL. Clicking it runs that code on the page you are viewing. No extension, no installation, works in Safari, Firefox, Chrome and Edge, on macOS and Windows alike — including a locked-down work computer, since it is just a bookmark.

Noema's bookmarklet reads the page's title, description and og:image from the live page you are looking at. That is why it works even for Instagram and Facebook: you are logged in, so the data is there in the page — while a server fetching the same URL anonymously would usually hit a login wall.

  1. Open the Links page and find the dashed “+ Noema” button at the bottom.
  2. Drag it (don't click) into your browser's bookmarks bar:
    • Safari (Mac) — show the Favourites bar with ⌘⇧B (View → Show Favourites Bar), then drag the button onto it.
    • Firefox (Windows/Mac) — show the Bookmarks toolbar with Ctrl⇧B / ⌘⇧B, then drag the button onto it.
    • Chrome / Edge — Ctrl⇧B (⌘⇧B on Mac) shows the bookmarks bar; drag the button onto it.
  3. Browse anywhere. When a page is worth keeping, click the bookmarklet — a small window opens, the link is saved with its preview, and you can close the window or assign a label right there.
Keyboard shortcut In Safari, the first nine items of the Favourites bar get automatic shortcuts ⌘1–⌘9 — put the bookmarklet first and saving a page becomes a single keystroke. In Firefox, you can assign a keyword to the bookmarklet (right-click it → Edit bookmark → Keyword, e.g. nl), then type nl in the address bar and press Enter.
One thing to know The bookmarklet opens a window on your Noema address, so your Noema server must be reachable from that computer (e.g. your public PUBLIC_BASE_URL, or the LAN address at home). If the UI password is enabled, the browser will ask for it once and remember it.

iPhone & iPad — share sheet via the Shortcuts app

On iOS the natural flow is the share sheet: you see a post in the Instagram or Facebook app, tap Share → Send to Noema, done. This uses Apple's built-in Shortcuts app and Noema's machine API (/api/tools/link_add), which stays reachable even when the UI password is on — it is protected by your NOEMA_API_TOKEN instead.

  1. Open the Shortcuts app → + to create a new shortcut.
  2. Tap the info (ⓘ) bar → enable “Show in Share Sheet”. Under “Receive”, limit input types to URLs (and Safari web pages).
  3. Add the action “Get URLs from Input”.
  4. Add the action “Get Contents of URL” and configure it:
    • URL: https://<your-noema>/api/tools/link_add
    • Method: POST
    • Headers: Authorization = Bearer <your NOEMA_API_TOKEN>
    • Request Body: JSON with one field — key url, value = the URLs variable from the previous step. Optionally add a fixed label field (e.g. phone).
  5. Name it “Send to Noema”. It now appears in the share sheet of every app — Instagram, Facebook, Safari, YouTube…

The server fetches the page's Open Graph metadata itself in this flow. The same shortcut works on macOS too (Shortcuts is on the Mac since Monterey), and you can ask Siri to run it by name.

Instagram / Facebook previews Meta aggressively walls off anonymous scraping, so links saved via the share sheet (server-side fetch) sometimes come through without an image or with a generic title. Links saved with the bookmarklet on desktop don't have this problem, because the metadata is read from your logged-in page. You can always fix a title or label later on the Links page.

For LLMs too

The linkdump is part of the gateway like everything else: link_add and link_list are exposed over MCP and OpenAPI, so you can tell Claude “save this link under ‘reading'” or ask “what did I save last week about kitchens?”.

08 Google Calendar (optional)

Noema can show your Google Calendar events for a given day inside the “today” column, read-only. The connect flow is built in — no OAuth Playground needed:

  1. In Google Cloud, enable the Google Calendar API and create an OAuth client (Web).
  2. Set the redirect URI to <PUBLIC_BASE_URL>/auth/google/callback.
  3. Put GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET in .env and start the server.
  4. Open /auth/google, click Allow — the refresh token is saved into data/ (never committed to git).

The scope is read-only (calendar.readonly); recurring events are expanded into concrete instances.

09 Backup & snapshots

On the Backup page you can:

  • Download a full backup of tasks, notes, documents and links as a single JSON file.
  • Restore from such a file (this replaces current data).
  • Take a snapshot kept on the server, and restore any previous snapshot later.
On disk Data files in data/ are stored AES-256-GCM encrypted at rest. A downloaded backup, however, is plain JSON — keep it somewhere safe.

10 MCP & OpenAPI gateway

Every Noema capability is defined once in a tool registry and exposed three ways at the same time, so they can never drift apart:

  • MCP — POST /mcp (Model Context Protocol, Streamable HTTP, stateless) for Claude / ChatGPT.
  • OpenAPI 3.1 — GET /openapi.json, auto-generated, for agents and Siri Shortcuts.
  • REST — POST /api/tools/<name> to call any tool directly.

Connect from Claude / ChatGPT

Add Noema as an MCP server in your client's config:

{
  "mcpServers": {
    "noema": {
      "url": "http://localhost:3000/mcp"
    }
  }
}

Then ask, in plain language: “What's left for me today?” — the client calls todo_summary / todo_list behind the scenes.

Available tools

ToolWhat it does
todo_listTasks grouped by day (yesterday/today/tomorrow).
todo_addAdd a task (title, day, priority, time, repeat).
todo_completeMark a task done / reopen it (id).
todo_deleteDelete a task (id).
todo_summaryShort summary: counts per day + titles of open tasks.
calendar_eventsGoogle Calendar events for a day (needs a connected calendar).
link_addSave a link to the linkdump (url, optional title, description, image, label). Missing metadata is fetched from the page.
link_listList saved links, newest first (q search, label filter, limit).

11 Siri & OpenAI — via Keryx

For Siri and OpenAI integration Noema relies on Keryx, a separate companion project that acts as the bridge (Siri Shortcuts / OpenAI). Noema shares the same gateway pattern as Keryx — the OpenAPI schema Noema generates is exactly what Siri Shortcuts and OpenAI tool-use expect — but Noema runs in a light theme around the three-day board instead of Siri shortcuts.

12 Auth & security

  • UI password (UI_PASSWORD) — optional HTTP Basic password protecting the whole web UI and its REST routes. The machine endpoints (/mcp, /openapi.json, /api/tools/*, OAuth, /healthz) stay public. Empty = UI is public.
  • Gateway token (NOEMA_API_TOKEN) — optional bearer token machine clients must send (Authorization: Bearer <token>). Empty = auth disabled (local dev only).
  • Encryption (ENCRYPTION_KEY) — if set, the data key is derived from it (scrypt) and only the salt is stored on disk; if empty, a random local key is generated.
  • Rate limiting — repeated bad logins are throttled per IP, and all /api/* traffic is capped per minute.
Before exposing publicly If you put Noema on the open internet, set UI_PASSWORD (and ideally NOEMA_API_TOKEN), restrict NOEMA_CORS_ORIGIN, and serve it over HTTPS.

13 Interface tips

  • Quick Capture (CMD+K) — press Cmd + K (or Ctrl + K) from anywhere to open the global Inbox modal. Type a URL to save a Link, start with /n to create a Note, or just type text to add a Task for Today.
  • Theme — toggle light / dark with the ☾ / ☀ button in the footer. Your choice is remembered.
  • Text size — the footer A− / 100% / A+ buttons scale the whole interface.
  • System stats — the footer shows live CPU / RAM / Disk of the server Noema runs on.
  • Menu — the button top-right opens the side menu with links to Archive, Notes, Documents, Links, Help and Backup.
  • Search — on the Archive page, press / to jump straight to search.
